Weekly Focus

Settings

Appearance

Time of day turns to evening at 5pm and night from 7pm until 6am.

The cats

After bedtime, anything new you add for today gets scratched over to tomorrow. Switch this off if you really need to add something late.

Goals

Bigger things you're working towards. They appear as plants while you plan, so you can give them a step.

Alarm shortcut

The last step of each plan sets your alarm through an Apple Shortcut.

  1. In Shortcuts, make a shortcut with the exact name above.
  2. Let it receive Text, then add Get Dates from Input.
  3. Add Create Alarm using those dates. Names can differ a little between iOS versions.
  4. Add this page to your Home Screen and set alarms with Set alarm at the end of each plan.

Sync with GitHub

Your data lives as one file in a private repo you control. These details stay in this browser.

Use a fine-grained token with Contents read and write on this repo only.
